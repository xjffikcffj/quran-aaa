# القرآن الصوتي (Quran Audio Android App)

تطبيق أندرويد أصلي مكتوب بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** للاستماع إلى سور القرآن الكريم الـ114 كاملةً وتنزيلها للاستماع دون اتصال بالإنترنت.

## المميزات الأساسية
- **السور والبحث العربي الذكي**: عرض جميع السور الـ114 مع تطبيع البحث العربي والأرقام الهندية، والمفضلة المحفوظة محلياً.
- **القراء المعتمدون والمخصصون**: 8 قراء معتمدين بمصاحف كاملة (114 سورة)، مع دعم إضافة قراء مخصصين عبر روابط `HTTPS` وحفظهم في قاعدة بيانات `Room`.
- **مشغل صوت متقدم بالخلفية**:
  - إدارة الطلبات المتتابعة عبر معرّف طلب فريد ومهلة زمنية للتحميل، ومعالجة انقطاع الشبكة والتركيز الصوتي (`AudioFocus`).
  - خدمة خلفية (`QuranAudioService`) متكاملة مع `MediaSessionCompat` وإشعار التحكم وشاشة القفل.
  - التحكم بسرعة القراءة (`0.75x` إلى `2.0x`) والتكرار ومؤقت النوم (`END_OF_SURAH` ومؤقت زمني).
- **التنزيلات والاستماع دون إنترنت**:
  - تنزيل عبر `OkHttp` مع التحقق من سلامة ملفات MP3 ودعم استئناف التنزيل (`Range`) ومرايا `Archive.org`، وإلغاء فوري لطلبات الشبكة.
- **الإشارات المرجعية، تذكير الجمعة، والنسخ الاحتياطي**:
  - حفظ المواضع والملاحظات، وتذكير محلي أسبوعي بسورة الكهف صباح الجمعة عبر `AlarmManager`.
  - تصدير واستيراد نسخة احتياطية كاملة (`JSON v2`) تشمل المفضلة والإشارات ومواضع الاستماع والقراء المخصصين ضمن معاملة ذرية واحدة.

## البنية التقنية
- **المعرّف**: `com.aistudio.quranaudio.yqtnzp`
- **البيانات المحلية**: `Room` (`version = 2` مع ترحيل `MIGRATION_1_2`) + `SharedPreferences`.
- **الشبكة والصوت**: `OkHttp` + `Android MediaPlayer` + `MediaSessionCompat`.
- **الإعلانات**: Google AdMob Banner وInterstitial مع إدارة الموافقة `UMP`.

## أوامر البناء والاختبار (Gradle)
```bash
# تشغيل اختبارات الوحدة وRobolectric
gradle :app:testDebugUnitTest

# فحص Android Lint
gradle :app:lintDebug

# بناء نسخة Debug APK
gradle :app:assembleDebug

# بناء نسخة Release APK و AAB الموقّعتين (مع متغيرات بيئة التوقيع)
KEYSTORE_PATH=/path/to/release.jks STORE_PASSWORD=... KEY_PASSWORD=... \
  gradle :app:assembleRelease :app:bundleRelease
```
