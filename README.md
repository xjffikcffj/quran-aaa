# القرآن الصوتي (Quran Audio Web App)

تطبيق ويب متكامل مبني بـ **React** و **TypeScript** و **Tailwind CSS** للاستماع إلى سور القرآن الكريم الـ114 كاملةً وتنزيلها في المتصفح للاستماع دون اتصال بالإنترنت.

## المميزات الأساسية
- **السور والبحث العربي الذكي**: عرض جميع السور الـ114 مع تطبيع البحث العربي والأرقام الهندية (`١٨` / `18`)، والمفضلة المحفوظة محلياً.
- **القراء المعتمدون والمخصصون**: 8 قراء معتمدين بمصاحف كاملة (114 سورة)، مع دعم إضافة قراء مخصصين عبر روابط `HTTPS` وحفظهم في `IndexedDB`.
- **مشغل صوت متقدم**:
  - إدارة الطلبات المتتابعة عبر معرّف طلب فريد ومهلة زمنية للتحميل (`20s`)، وإعادة المحاولة التلقائية عند تعثر الشبكة.
  - التكامل مع `MediaSession API` لأزرار التحكم على مستوى النظام والمتصفح.
  - التحكم بسرعة القراءة (`0.75x` إلى `2.0x`) والتكرار (`ALL` / `ONE` / `NONE`) ومؤقت النوم (`END_OF_SURAH` ومؤقت زمني).
- **التنزيلات والاستماع دون إنترنت**:
  - تنزيل ملفات MP3 عبر `Fetch` مع تتبع التقدم، والتحقق من ترويسات `ID3v2` و `MPEG Layer III`، ودعم مرايا `Archive.org`، وحفظ الملفات في `IndexedDB`.
- **الإشارات المرجعية، تذكير الجمعة، والنسخ الاحتياطي**:
  - حفظ المواضع والملاحظات، وتجربة إشعار تذكير يوم الجمعة عبر `Web Notifications API`.
  - تصدير واستيراد نسخة احتياطية كاملة (`JSON v2`) تشمل المفضلة والإشارات ومواضع الاستماع والقراء المخصصين.

## أوامر التطوير والبناء
```bash
npm install
npm run dev
npm run lint
npm run build
```
